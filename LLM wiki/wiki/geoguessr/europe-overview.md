# GeoGuessr 歐洲概覽速判 (Europe Overview)

## 核心速判決策樹 (3 秒定國別)

```
1. 觀察行駛方向：
   - 靠左走 ──> 只有 4 國：英國 (UK)、愛爾蘭 (IE)、馬爾他 (MT)、賽普勒斯 (CY)
   - 靠右走 ──> 進入步驟 2

2. 觀察車牌顏色與條紋：
   - 全黃牌（前後皆黃） ──> 荷蘭 (NL) 或 盧森堡 (LU)
   - 右側有黃條 ──> 葡萄牙 (PT)
   - 兩側皆有藍條且車牌短小 ──> 義大利 (IT) 或 阿爾巴尼亞 (AL)
   - 純白無歐盟藍條 ──> 瑞士 (CH)、挪威舊牌、西巴爾幹、烏克蘭、俄羅斯
   - 紅字白底 ──> 比利時 (BE)

3. 觀察特殊街景車與相機：
   - 天空有撕裂縫 / 紅車 ──> 阿爾巴尼亞 (AL)
   - 低視角相機 (Low Cam) ──> 瑞士 (CH)
   - 紅色前車頭 / 天線 ──> 烏克蘭 (UA)

4. 觀察防撞桿與電線桿：
   - 水泥洞洞桿（密集小孔） ──> 羅馬尼亞 (RO) 或 匈牙利 (HU)
   - 黑頂帽子斜切白柱 ──> 德國 (DE) 或 奧地利 (AT)
   - 圓柱紅白帶 ──> 法國 (FR)
```

## 歐洲主要分區直覺特徵
| 區域 | 代表國家 | 關鍵特徵 |
| :--- | :--- | :--- |
| **不列顛群島** | 英國、愛爾蘭 | 靠左行駛；愛爾蘭有黃色邊線；英國前白後黃車牌 |
| **伊比利半島** | 西班牙、葡萄牙 | 葡萄牙車牌右側黃條 + 5 條斑馬線；西班牙護欄黃反光片 + 8 條斑馬線 |
| **北歐五國** | 挪威、瑞典、芬蘭、丹麥、冰島 | 挪威黃色中心虛線 + 綠商用車牌；瑞典短虛線邊線；冰島黃細桿防撞桿 |
| **中歐西歐** | 法國、德國、荷蘭、比利時 | 荷蘭全黃牌；比利時紅字；德國奧地利黑帽防撞桿；法國紅白圓桿 |
| **東歐與巴爾幹** | 波蘭、捷克、羅馬尼亞、匈牙利、阿爾巴尼亞 | 羅馬尼亞/匈牙利洞洞桿；阿爾巴尼亞天空裂痕；波蘭黑底白桿 |
