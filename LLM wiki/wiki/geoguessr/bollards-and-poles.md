# 歐洲防撞桿與基礎設施 (European Bollards and Poles)

在鄉村或無車輛地區，路邊防撞桿（Bollards）與電線桿（Utility Poles）是準確度最高的地標特徵。

---

## 1. 經典防撞桿（Bollards）秒殺圖譜

| 國家 | 形狀與塗裝 | 關鍵細節 |
| :--- | :--- | :--- |
| **德國 / 奧地利** | 白色扁柱 + 黑色傾斜頂帽 | 正面為斜長方形黑底包白色反光片；交叉路口處反光片變為橘色 |
| **法國** | 白色圓柱體 | 頂部環繞一道紅色反光帶（或下方貼有藍色/白色貼紙） |
| **義大利** | 白色矩形水泥柱 | 斜切頂部，正面鑲嵌長方形紅色反光條 |
| **波蘭** | 白色圓柱 + 黑色底座 | 柱身中央有直立紅色反光矩形片 |
| **西班牙** | 白色圓柱矮桿 | 正面為黃色或白色圓形/小長方形反光片 |
| **冰島** | 細長鮮黃色柱體 | 全歐洲唯一全柱通體黃色的防撞桿 |
| **挪威** | 白底長桿 + 橘色反光條 | 常伴隨黃色中心道路虛線 |
| **瑞典** | 白色長桿 + 黑色方塊中嵌小白方塊 | 反光片為極其特殊的雙層「回」字幾何結構 |

---

## 2. 電線桿特徵（Poles）

### 水泥洞洞桿（Holey Concrete Poles）
東歐特有的預應力水泥桿，表面整齊排列通孔：
- **羅馬尼亞 (RO)**：密集小橢圓孔，且桿上高機率釘有黃色閃電三角形警告鐵牌。
- **匈牙利 (HU)**：長型圓孔，形狀如爬梯。
- **波蘭 (PL)**：梯形雙併混凝土柱。

### 金屬支架木桿
- **法國 / 西班牙**：鄉間電線桿常為木桿頂部加裝六角形或橫向輕量化金屬支架。

---

## 3. 防撞護欄（Guardrails）
- **西班牙 / 安道爾**：金屬 A 型防撞護欄側面，固定釘有「黃色長條矩形反光片」。
