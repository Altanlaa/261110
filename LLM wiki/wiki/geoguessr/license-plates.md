# 歐洲車牌速判 (European License Plates)

車牌是 GeoGuessr 中最快速且最具決定性的秒殺線索。雖然 Street View 會模糊車牌號碼，但顏色分佈與邊緣色塊依然極為清晰。

---

## 核心車牌分類對照表

| 車牌外觀特徵 | 對應國家 | 補充區分細節 |
| :--- | :--- | :--- |
| **全黃牌（前牌與後牌皆為黃色）** | **荷蘭 (NL)**、**盧森堡 (LU)** | 荷蘭為平原、紅色自行車道；盧森堡多丘陵與黑色石板屋頂 |
| **前白後黃（前牌白、後牌黃）** | **英國 (UK)**、**直布羅陀 (GI)** | 英國靠左行駛；直布羅陀靠右行駛且地勢為巨岩山峰 |
| **右側帶有黃色條紋** | **葡萄牙 (PT)** | 2020 年前發行之經典車牌，街景中佔比極高 |
| **前後皆具雙藍條（左藍右藍，車牌偏短小）** | **義大利 (IT)**、**阿爾巴尼亞 (AL)** | 義大利前牌極窄小；阿爾巴尼亞天空有裂痕且常伴隨紅車 |
| **白底紅字 / 紅色邊框** | **比利時 (BE)** | 字體模糊時呈現微紅暈影 |
| **全白牌（無歐盟左側藍色條紋）** | **瑞士 (CH)** | 瑞士車牌小巧純白；亦可見於挪威與冰島之舊款車輛 |
| **綠底車牌** | **挪威 (NO)** | 挪威特有之雙人座商用車牌，辨識度 100% |
| **白底黑字帶頂部/底部紅細線** | **奧地利 (AT)** | 奧地利邦徽紅邊模糊後的特有紅色反光 |

---

## 避坑要點
1. **法國與西班牙**：皆為標準歐盟藍條白牌，不可單靠車牌區分，需結合防撞桿（Bollard）與斑馬線。
2. **英國計程車與商用車**：在愛爾蘭偶爾會見到跨境英國車輛，需以「道路邊線是否為黃色（愛爾蘭有）」二次確認。
