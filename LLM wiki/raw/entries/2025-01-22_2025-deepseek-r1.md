# DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning

# DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning

## 摘要與核心貢獻
DeepSeek-AI 發表 DeepSeek-R1 技術報告，探索在大語言模型中純粹依賴強化學習（Reinforcement Learning, RL）激發複雜邏輯推理能力的可行性。

核心貢獻包含：
1. **DeepSeek-R1-Zero**：在不進行監督式微調（Supervised Fine-Tuning, SFT）冷啟動的前提下，直接於預訓練底座模型（DeepSeek-V3-Base）上運行純強化學習。實驗發現模型自主湧現出「自我驗證（Self-verification）」、「回溯探索（Backtracking）」與「長思維鏈（Long Chain-of-Thought）」等推理行為。
2. **DeepSeek-R1**：為解決 R1-Zero 出現的語言混雜、可讀性差等問題，引入少量高質量長思考冷啟動資料（Cold-start data），結合多階段訓練管線（Cold-start SFT -> Reasoning RL -> Rejection Sampling SFT -> Full-scenario RL），在 AIME 2024、MATH-500 等數學競賽基準上達到與 OpenAI-o1 正式版相當的水準。
3. **知識蒸餾（Distillation）**：證明利用 R1 產生的 80 萬條高質量推理資料，直接微調密集模型（如 Qwen-2.5-32B、Llama-3.3-70B），其推理能力遠勝過直接在小模型上做 RL。
4. **Group Relative Policy Optimization (GRPO)**：捨棄傳統 PPO 的 Critic 模型，改透過分組取樣多個候選輸出的相對表現計算 Advantage，顯著降低訓練記憶體消耗與系統複雜度。
